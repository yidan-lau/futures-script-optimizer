# 测试案例 006：语义违规无禁词（懂得都懂类）

## 元信息

## 原稿
```text
看完我们三立期货的手续费，真的就是懂得都懂，懂行的自然明白！
```

## 预期
- 诊断：命中编号 36「看完我们的手续费真的就是懂得都懂」——隐晦语暗示费率低，无传统禁词。
- 合规结论：A 类命中，停止使用；不得用隐晦语暗示费率优惠。
- 关键验证：Skill 不能因「没有明显禁词」而判合规，须识别语义违规。
- 通过标准：识别「懂得都懂」为隐晦低价暗示并删除/改写。
