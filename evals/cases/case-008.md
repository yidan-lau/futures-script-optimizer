# 测试案例 008：语境依赖（降本增效 / 有福了）

## 元信息
- ID：case-008 ｜ 版本：v0.1.2 ｜ 重点：合规（语境依赖）｜ 难度：进阶

## 原稿
```text
家人们有福了！来三立期货开户，降本增效，手续费直接给你优惠，保证金也有福了！
```

## 预期
- 诊断：
  - 「家人们有福了」→ 命中编号 48（福利化噱头）。
  - 「降本增效」→ 命中编号 38，中性词用于低价引流语境即风险。
  - 「保证金也有福了」→ 原资料明确「保证金不能说有福了」。
- 合规结论：A 类命中；「降本增效」在引流语境禁用。
- 关键验证：区分语境——「降本增效」非绝对禁词，但在开户引流语境下需删除；「保证金有福了」绝对不行。
- 通过标准：删除「有福了」福利化表述；「降本增效」在引流语境下删除。
