# 脚本优化案例修改规律

> 来源：《跑量脚本优化前后案例分析_E33.xlsx》（41 条案例，含「规律汇总」「可直接转化为 Skill 规则」工作表）+《优化前后案例+爆款脚本.xlsx》。
> 可信度分级见 `knowledge-sources.md`：A 类通用规则可写入主规则；B 类特殊处理作条件分支；C 类证据不足禁止当正式规则。

## 一、A 类通用规则（多案例反复出现）

### A1 结构类

| 规则 | 说明 | 依据 |
|------|------|------|
| 补三段式 | 素材无分段时，统一补「钩子 / 卖点（展示卖点）/ 转化」三段式 | 15 条案例 |
| 补 CTA | 素材无 CTA 时，必须补明确转化引导（点击/咨询/领表） | 6 条案例；F028 批注「脚本结构按钩子、卖点、转化制作」 |
| 福利配利益解释 | 每个核心福利补充「对用户的好处」（如宽松保证金→仓位调度从容） | 4 条案例 |
| 压缩科普 | 科普/说明类内容大幅压缩，尽快进入福利与转化 | 5 条案例；F028 批注「科普时间太长，客户听不到转化就划走」 |
| 删冗余排比 | 删除重复排比与冗余信息，同类福利只讲一遍 | 5 条案例 |

### A2 合规类（改写时必须执行）

| 规则 | 处理 | 依据 |
|------|------|------|
| 去「低成本」类表述 | 「低成本/低手续费/成本低/成本更低/低成本入场/低成本渠道/降低交易成本」一律删除或替换为「优惠/合理/灵活/清晰」 | 13 条案例；F006 批注「不可以出现低手续费、低保证金」 |
| 删同行比较 | 「很多平台/打破行业常规/行业有竞争优势/别人低费率」→ 删除 | 5 条案例 |
| 弱化绝对化/夸张 | 「超低/大幅/巨款/一半利润/多花好几倍/天差地别」→ 弱化或删除 | 5 条案例 |
| 删「无套路」类 | 「无套路/零套路/不玩口头套路」→ 删除 | 5 条案例 |
| 弱化具体承诺 | 具体金额/服务承诺 → 弱化（「几千元可起步」→「以交易所和公司公示为准」） | 4 条案例 |
| 删收益承诺 | 「盈利更实在」等 → 删除 | 1 条案例 |
| 剧情演绎标注 | 剧情演绎类需标注「剧情演绎，内容真实有效」 | 1 条案例 |
| 等级修饰词弱化 | 「大户级/至尊级/贵宾级」等等级修饰词一律弱化为标准「VIP 手续费」 | 业务方 2026-10-10 确认 |
| 「免费」表述 | **「免费研报」可以说**；其他具体「免费」事宜（如免费工具/免费服务/免费测算）**视情况而定**，无明确口径时转人工确认 | 业务方 2026-10-10 确认 |
| 保留合规背书 | 中期协可查、证监会持牌、银行三方存管、费率书面留痕 → 保留并强化 | 8 条案例 |

> 注意：A2 合规规则与 `compliance-rules.md` 的 A/D 类条目存在交叉，执行时以合规知识库为准，案例规律仅作改写参考。

### A3 Hook 规则

- 素材无 Hook 时新增 Hook（7 条案例）。
- 口号/宣言式开头改为痛点或悬念开头（4 条案例）。
- 加入目标人群点名（股民/上班族）强化精准推送（2 条案例）。
- 开头点明主要客群定位：费率敏感型客户、小资金客户居多、有开户意向群体（对应优化稿开头标签「优惠手续费/新客开户/小资金」的官方含义，业务方 2026-10-10 确认）。
- 强挽留/情绪化开场降低广告感（3 条案例）。
- 核心卖点前置进 Hook（夜盘/T+0/三个坏习惯）（3 条案例）。
- 科普型脚本按秒级时间轴规划 0-4s 钩子（2 条案例）。

### A4 Content 规则

- 无分段长文按「痛点 → 福利 → 服务 → 资质背书 → 收口」重组（12 条案例）。
- 删无效信息（与主卖点无关的指标/教学/画面描述）（5 条案例）。
- 口语化重写，书面长句拆成短句（4 条案例）。
- Q&A/对话体压缩轮次，删多余问答（3 条案例）。
- 正文风险提示句（如「严控仓位才是交易核心」）去留**视脚本定位而定**：营销/转化导向脚本可精简非必要的说教式提示句；教育/科普导向脚本可保留。判断依据是脚本定位而非内容是否违禁（业务方 2026-10-10 确认）。
- **禁止具体品种推荐**：不点明具体期货品种名（如螺纹钢、玉米、玻璃），涉及品种时改为「热门品种」「你关注的品种」等泛称（业务方 2026-10-10 确认）。

### A5 CTA 规则

- 素材无 CTA 时补 CTA（6 条案例）。
- CTA 动作具体化：领取费率表/免费测算/1对1梳理/咨询开户权益（8 条案例）。
- CTA 加紧迫感/利益点（立即/马上/同样的资金更多机会）（5 条案例）。
- CTA 精简去重（6 条案例）。

## 二、B 类特殊处理（仅特定案例，作条件分支）

| 场景 | 处理方式 | 案例 |
|------|---------|------|
| 剧情演绎内容 | 标注「剧情演绎，内容真实有效」；场景「追车」→「追人」 | F030 |
| 多人称称呼 | 只保留开头和结尾的「朋友」称呼 | F025 |
| 具体金额承诺 | 改为「以交易所和公司公示为准」 | F033 |
| 科普脚本 | 按秒级时间轴【0-4s/4-11s/11-18s/18-25s/25-30s】重构 | F043/F044 |
| 卖点呼应 Hook 主题 | 钩子讲卡顿 → 卖点讲系统稳定 | F020 |
| 压缩科普 + 补 CTA | 按批注压缩科普、补 CTA | F028 |

## 三、C 类证据不足（禁止当正式规则，需人工确认）

以下事项证据不足或口径矛盾，**Skill 遇到时不得自行判定，一律转人工**：

1. **「甩开同行」「立省交易成本」**：F041 保留「甩开同行」、F017 用「立省交易成本」，与其他案例「删同行比较」「低成本不能提」矛盾。
2. **案例跳号**：原始编号 7、11、31 缺失原因未确认。
3. **F009/F010/F012 无修改**：是否本身为达标基准稿未确认。

> 已由业务方确认、不再属于 C 类证据不足（见 `compliance-rules.md`「业务方口径澄清」及本文 A2/A3/A4 规则）：
> - 「无压力保证金」→ 可使用。
> - 「系统稳不卡顿」→ 合规可说，但不作为营销点频繁出现。
> - 「7×24 小时客服」→ 脚本不使用，统一改「客户经理 1v1 服务」。
> - 「大户级/至尊级」等等级修饰词 → 一律弱化为标准「VIP 手续费」。
> - 正文风险提示句去留 → 视脚本定位而定（非统一删/留）。
> - 「免费研报」→ 可以说；其他具体「免费」事宜 → 视情况而定，无明确口径转人工。
> - 开头标签含义 → 开头点明主要客群（费率敏感型 / 小资金居多 / 有开户意向）。

## 四、统计口径（供测试评分参考）

41 条案例中：
- 合规修改确认 20 条（另有 6 条待确认）。
- 补三段式结构 15 条。
- 无 CTA 补 CTA 6 条。
- Hook 有变化 33 条（完全重写 4 条）。
- 素材自带修改批注 7 条（最可靠证据）。
- 科普脚本时间轴重构 2 条。
- 无实质修改 3 条（F009/F010/F012）。

目标人群分布：新手/新客/散户 19 条；短线/高频/波段 7 条；股民 3 条；上班族 2 条；小资金 3 条；其他/通用 11 条。
